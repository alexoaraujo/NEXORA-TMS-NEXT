## Important evidence status
This document records implementation evidence, not a claim that the SQL has already been executed against Neon. Runtime database execution requires a configured migration/test connection and must be captured by CI or an isolated test environment.

## Security invariant
The client cannot select another tenant by changing a request `tenant_id`; authorization establishes the tenant context and PostgreSQL RLS enforces the row boundary.
